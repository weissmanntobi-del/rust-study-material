# Rust Beginner Roadmap

This roadmap is for developers who are new to Rust.

The goal is to move from basic syntax to small real projects.

---

## Phase 1: Learn Basic Syntax

Learn:

- variables
- mutability
- data types
- functions
- control flow
- loops
- comments
- basic Cargo commands

Practice:

- write small functions
- use `if`, `match`, `loop`, `while`, and `for`
- create a new Rust project with Cargo

Commands to know:

```bash
cargo new my_project
cargo run
cargo build
cargo test
