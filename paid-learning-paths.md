# Paid Structured Learning Paths

This GitHub repository is free.

I also created paid Rust learning bundles for developers who want a more structured learning path.

You do not need to buy anything to use this repository.

The paid bundles are for people who prefer organized material instead of collecting random resources from many places.

---

## Rust Beginners Learning Bundle

Best for:

- complete Rust beginners
- developers who want to start from zero
- people who want small real projects
- learners confused by ownership and borrowing

Link:

https://tobiweissmann.gumroad.com/l/louvvk

---

## Rust for Java Developer

Best for:

- Java developers
- Spring Boot developers
- backend engineers
- developers moving from JVM systems to Rust

Covers ideas like:

- ownership vs garbage collection
- traits vs interfaces
- Result vs exceptions
- Option vs null
- Axum vs Spring Boot
- Rust backend project structure

Link:

https://tobiweissmann.gumroad.com/l/etcbtr

---

## Async Rust

Best for:

- developers who know Rust basics

- people building concurrent services

- async/await
- futures
- Tokio
- tasks
- channels
- timeouts
- concurrent APIs
- background workers
